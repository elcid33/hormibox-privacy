2. Principios de privacidad

HormiBox es una aplicación Android de gestión de inventarios diseñada para funcionar localmente en el dispositivo del usuario.

La aplicación no requiere crear una cuenta, no incorpora publicidad ni tiene como finalidad recopilar información para elaborar perfiles de usuarios, realizar seguimiento publicitario o vender datos personales.

El objetivo es que el usuario pueda gestionar sus objetos e inventarios sin tener que enviar su información a un servicio en la nube.

3. Información que puede tratar la aplicación

El usuario puede introducir o guardar información para organizar sus inventarios, entre ella:

  • Nombres, descripciones, cantidades y categorías de objetos.
  • Ubicaciones, trasteros, cajas y almacenes.
  • Referencias, SKU, proveedores y movimientos de existencias.
  • Fotografías, códigos QR y datos relacionados con los objetos.
  • Texto reconocido mediante OCR y sugerencias de clasificación.

La aplicación también puede procesar datos derivados de estas entradas para calcular existencias y organizar la información.

Si el usuario introduce datos personales de otras personas en los campos de inventario, debe hacerlo únicamente cuando tenga una finalidad legítima para ello.

4. Almacenamiento local y ausencia de cuentas

Los datos de inventario se almacenan localmente en el dispositivo. HormiBox no necesita una cuenta de usuario ni un servidor propio para sus funciones de inventario.

En la versión auditada, la aplicación no declara el permiso Android INTERNET. Por tanto, la versión examinada no dispone del permiso ordinario de Android para establecer conexiones de red desde la aplicación.

La política de funcionamiento de HormiBox es no transmitir el inventario, las fotografías ni los resultados del OCR a servidores del desarrollador, servicios publicitarios, plataformas de analítica o terceros.

5. Cámara, imágenes y reconocimiento de texto

HormiBox solicita acceso a la cámara para las funciones que permiten capturar imágenes de objetos o etiquetas.

Las imágenes se utilizan para las funciones de inventario que el usuario decida utilizar. El OCR y las sugerencias de categorías se procesan localmente mediante los componentes y modelos integrados en la aplicación, cuando corresponda.

La aplicación no está diseñada para enviar esas imágenes a Google ni a otros proveedores para analizarlas remotamente.

6. Servicios de Google y otros terceros

HormiBox no pretende utilizar servicios online de Google para sincronizar el inventario, crear perfiles, analizar el comportamiento del usuario o transmitir sus datos.

La versión auditada utiliza tecnología ML Kit para determinadas funciones locales de reconocimiento y clasificación. ML Kit es tecnología de Google, aunque el procesamiento mediante modelos integrados puede realizarse en el propio dispositivo.

Por transparencia, no se afirma que el código de la aplicación carezca de toda tecnología desarrollada por Google. La intención del producto es evitar comunicaciones externas y mantener el tratamiento de los datos del inventario en el dispositivo.

Si en una versión futura se incorpora una dependencia que transmita datos o un servicio externo, se revisará esta política antes de distribuir esa versión.

7. Publicidad, analítica y rastreadores

HormiBox no tiene previsto mostrar anuncios.

La aplicación no debe integrar SDK publicitarios, sistemas de seguimiento publicitario, herramientas de analítica de uso ni mecanismos destinados a crear perfiles de usuarios.

Esta declaración describe la política de producto. La versión publicada debe comprobarse para confirmar que sus dependencias y su comportamiento real respetan estos principios.

8. Exportaciones, importaciones y copias de seguridad

HormiBox puede permitir exportar información en formatos como CSV o PDF y generar copias de seguridad en archivos ZIP para su restauración.

Estos archivos pueden contener información del inventario. El usuario decide dónde guardarlos, si los copia a otro dispositivo y si los comparte con terceros.

La aplicación está configurada en la versión auditada para desactivar la copia de seguridad automática del sistema Android. Esto no elimina las copias que el usuario genere manualmente o guarde fuera de la aplicación.

9. Permisos

La versión auditada declara el permiso de cámara y un permiso técnico de Android relacionado con receptores de difusión no exportados.

La cámara solo debe utilizarse para las funciones que la necesitan. El usuario puede administrar los permisos desde los ajustes del dispositivo.

Los permisos y las funciones pueden cambiar en futuras versiones; la política se actualizará si esos cambios afectan a la privacidad.

10. Conservación y eliminación

Los datos permanecen en el dispositivo hasta que el usuario los elimina desde la aplicación, borra los datos de la aplicación o la desinstala.

Los archivos exportados, las copias ZIP y los archivos que se hayan guardado en otras ubicaciones pueden permanecer después de desinstalar HormiBox. El usuario debe eliminarlos por separado si desea borrarlos.

Como el inventario se mantiene localmente y no se envía a un servidor del desarrollador, el responsable no dispone de una copia remota del inventario que pueda eliminar por cuenta del usuario.

11. Seguridad

HormiBox está diseñada para reducir la exposición de los datos evitando su transmisión a servidores y desactivando la copia de seguridad automática del sistema en la versión auditada.

Ningún sistema puede garantizar una seguridad absoluta. El usuario debe proteger su dispositivo mediante bloqueo de pantalla y mantener bajo control los archivos exportados y las copias de seguridad.

12. Privacidad de menores

HormiBox es una herramienta de inventario general y no está diseñada específicamente para recopilar información personal de menores.

Si un usuario introduce información personal en la aplicación, esta se trata conforme al funcionamiento local descrito en esta política.

13. Derechos de protección de datos

Cuando resulte aplicable la normativa de protección de datos, los usuarios podrán ejercer los derechos que les correspondan, incluidos los de acceso, rectificación, supresión, limitación u oposición, mediante el contacto indicado en esta política.

El responsable no puede acceder a los datos que permanezcan exclusivamente en el dispositivo. El usuario puede gestionar esos datos directamente desde la aplicación y el sistema operativo.

Los usuarios también pueden dirigirse a la autoridad de protección de datos competente si consideran que sus derechos no han sido respetados.

14. Cambios en la política

Esta política podrá actualizarse cuando cambien las funciones, dependencias, permisos o prácticas de tratamiento de datos de HormiBox, o cuando lo exija la legislación aplicable.

La versión vigente estará disponible en esta página pública.
